Opciones basicas del correo de confirmacion

Correo automatico

Enviar un correo al cliente cuando se abre un ticket

Se muestra en el campo "De" junto al correo. Ej.: Soporte <soporte@dominio.com>

Puedes usar variables como {{ '{{codigo}}' }} o {{ '{{nombre}}' }}

Incluir informacion y conversacion

Insertar la tabla de informacion del cliente y el historial de la conversacion en el cuerpo

Enviar copia en tickets del asesor

Tambien enviar el correo cuando el ticket lo crea un asesor (por ejemplo desde el chat de WhatsApp)

Adjuntar archivos

Mostrar los archivos adjuntos del ticket en el correo de confirmacion
